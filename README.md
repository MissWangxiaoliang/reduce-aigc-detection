# Reduce AIGC Detection | 降低AIGC检测率

> 一套系统化的方法，用于降低 AI 生成内容（AIGC）被检测工具识别的概率。核心思路不是"欺骗检测工具"，而是让 AI 辅助生成的内容更接近真实人类写作风格。

## 📖 项目简介

本项目提供一套完整的 **AIGC 降检测方法论**，涵盖从理解检测原理到实战改写的全流程。适用于学术论文、毕业论文、报告综述等需要降低 AI 生成痕迹的中文/英文内容。

**核心理念**：降低 AIGC 检测率的本质不是"欺骗工具"，而是让 AI 生成的内容更接近真实人类写作风格。最独特、最不可替代的永远是人类的思考方式和个人经历。

---

## ✨ 功能特性

- 🔍 **检测原理分析** — 深入解读主流 AIGC 检测工具（GPTZero、Originality.ai、知网、Turnitin）的判断逻辑
- 📝 **三大核心方法** — Prompt 定向改写法、人工深度优化法、句式打散重构法
- 🔄 **AI 高频词替换词典** — 覆盖句首、句中、段尾的完整替换方案
- 📋 **多场景改写策略** — 针对论文摘要、文献综述、系统设计、测试报告等 9 种内容类型的定制策略
- ✅ **质量自检流程** — 三轮自检法（快速扫描 → 逐段检查 → 朗读测试）
- ⚠️ **避坑指南** — 明确标注绝对不能做的操作和容易忽略的细节
- 🌐 **中英文双语支持** — 提供中文和英文场景的改写 Prompt 模板

## 🚀 快速开始

### 1. 理解检测原理

在动手修改之前，先了解检测工具的三大核心指标：

| 检测维度 | 人工创作特征 | AI 生成特征 |
|---|---|---|
| **文本流畅度** | 存在轻微语法变化、逻辑小跳跃 | 过度流畅，句子结构高度统一 |
| **词汇多样性** | 同一概念用不同同义词交替使用 | 高频重复特定词汇或短语 |
| **语义连贯性** | 段落间可能存在轻微的逻辑断层 | 逻辑链过度严密，过渡"恰到好处" |

### 2. 选择适合的方法

| 方法 | 适用人群 | 操作耗时 | 预期通过率 |
|---|---|---|---|
| **Prompt 定向改写法** | 赶 deadline、快速降检测 | 10-30 分钟 | 90%+ |
| **人工深度优化法** | 时间充裕、要求高质量 | 1-3 小时 | 90%+ |
| **句式打散重构法** | 有写作基础、自主可控 | 30-60 分钟 | 85%+ |

### 3. 使用 Prompt 模板改写

将以下模板复制到 AI 对话工具中，替换 `[标题]` 和 `[内容]` 即可使用：

```
请你作为一名有10年科研经验的中文研究者，对以下内容进行专业的AIGC降检测改写。
改写要求完全符合中文论文/报告的表达习惯，同时彻底消除AI生成痕迹。

具体要求：
1. 对所有核心用词做自然的同义词替换，适当加入符合中文研究者写作习惯的衔接词；
2. 全面打散原有的句子结构，把长句拆成短句，把连续的短句合并成长短句结合的表达；
3. 在不改变原文核心观点和核心结论的前提下，结合研究主题增加10%-15%的个人研究感悟；
4. 全文保持学术写作的专业性，不改变原文的引用信息和核心数据，只改变表达方式。

论文/报告标题：《[替换为你的标题]》

需要改写的内容：
[粘贴你的AI生成内容，建议分段处理，每次500-1000字]
```

> 💡 **提示**：每次处理 500-1000 字效果最佳，不要一次性粘贴整篇长文。

### 4. 自检与验证

改写完成后，使用推荐检测工具验证：

| 工具 | 特点 | 合格标准 |
|---|---|---|
| **GPTZero** | 免费、快速，适合初筛 | Perplexity > 50, Burstiness > 1.5 |
| **Originality.ai** | 准确率高，支持学术论文 | AI 生成概率 < 10% |
| **知网 AIGC 检测** | 国内高校主流 | AI 生成占比 < 15% |
| **Turnitin** | 国际高校主流 | AI 生成概率 < 5% |

## 🛡️ 避坑提醒

| ❌ 错误操作 | 原因 |
|---|---|
| 中英回译法（中文→英文→中文） | 检测系统对机器翻译识别准确率接近 100% |
| 加乱码/特殊字符 | 自动过滤，且影响可读性 |
| 只改同义词不改结构 | 句子结构特征还在，一抓一个准 |
| 使用免费在线降检测工具 | 效果差，且有内容泄露风险 |
| 补充原文没有的内容 | 答辩时追问来源，无法回答反而暴露 |
